# Screenshots für die Projektdokumentation

Aufgenommen am 30.10.2026 mit dem tatsächlich eingesetzten Programmstand in
einer getrennten lokalen Docker-Vorschau. Alle fünf Laufzeitordner der
Vorschau waren von der normalen Anwendung getrennt. Es wurden ausschließlich
neutrale Startdaten und künstliche PDF-Prüfprojekte verwendet.

| Datei | Ansicht |
| --- | --- |
| `uebersicht.jpg` | Projektübersicht, Erfassungsstand und nächster Arbeitsschritt |
| `zip-export.jpg` | Gesamt-PDF, ZIP-Ausgabe und Reihenfolgeprotokoll |
| `anmeldung.jpg` | Anmeldemaske ohne eingetragene Zugangsdaten |
| `dokumentenmatrix.jpg` | Original-/Ausgabekapitel und Dokumentauswahl |
| `pdf-dokumentation.jpg` | PDF-Erzeugungsaktionen und Inhaltsbaum |

Das Musterprojekt `DEMO-2026` enthält zwölf Einzel-PDFs mit 20 Seiten.
Namen, Firmen und Projektangaben sind Beispiele. Die Bilder enthalten keine
echten Kontodaten, Projekte, Dateipfade zur privaten Ablage oder Sitzungswerte.

Die JPEG-Bilder zeigen die tatsächlich gerenderte Oberfläche in einem
schmalen Browserfenster. Die relevanten Ansichten wurden mit ihrem Seitenkopf
aufgenommen; Leerraum darunter wurde durch den Aufnahmeausschnitt begrenzt.
Oberflächeninhalte wurden nicht nachträglich verändert.

Bei größeren Designänderungen die Aufnahmen mit einer neuen getrennten
Demo-Installation erneuern. Keine bestehenden Projekte für öffentliche
Screenshots verwenden. Die Bilder werden relativ im Haupt-README verlinkt,
damit sie auch auf GitHub und in einem frischen Checkout erreichbar sind.
